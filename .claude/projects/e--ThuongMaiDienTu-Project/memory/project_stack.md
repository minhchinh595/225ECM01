Web thời trang (e-commerce clothing) project:
- **Backend**: Spring Boot 3.5.14, Java 21, Maven, PostgreSQL
- **Frontend**: Next.js with React, TypeScript, Shadcn UI
- **Database**: PostgreSQL database "webthoitrang" with 14 tables
- Port convention: Backend 8080 (default Spring Boot), Frontend 3000 (Next.js)

**Why**: Building complete e-commerce system with proper architecture
